# data_raw/

Taruh file export spreadsheet di sini:

- performance.xlsx (sheet 2026 dan Kuadran RM)
- portfolio.xlsx (sheet Tabel)
- realisasi.xlsx (sheet All)
- sla.xlsx (opsional, untuk halaman SLA; sheet yang judul kolomnya cocok)

Folder ini tidak bisa dibuka lewat browser (Live Server hanya melayani folder site/)
dan tidak ikut ke git. File boleh dihapus setelah `python pipeline/build_data.py` selesai.
