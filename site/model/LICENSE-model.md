# Model 3D Kirana

`kirana.vrm` saat ini adalah model contoh **VRM1_Constraint_Twist_Sample** karya pixiv Inc.
(dari repositori three-vrm), dengan tekstur diperkecil dan warna rambut, mata, serta atasan
diubah mendekati Kirana. Lisensi: VRM Public License 1.0
(https://vrm.dev/licenses/1.0/). Izin yang tercantum di model: dipakai siapa saja, boleh untuk
korporasi, boleh dibagikan ulang dan diubah, tanpa wajib mencantumkan nama.

Ganti file ini dengan model Kirana buatan sendiri dari VRoid Studio (nama file tetap `kirana.vrm`).
